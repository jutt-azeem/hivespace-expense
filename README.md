# HiveSpace Expenses

A Flutter expense tracker app for HiveSpace Coworking (Task 1).

## Features
- Expense and Category models (null-safe)
- MockRepository that returns sample expenses after a 500 ms delay
- HomePage that loads data in initState and shows it in a ListView.builder
- Error handling with try/catch
- Placeholder shown when the list is empty

## Setup
1. Install the Flutter SDK
2. Clone this repo
3. Run `flutter pub get`
4. Run `flutter run`
